## Detalles

En esta conversación se tuvo como objetivo extraer información relevante para conocer de qué forma se puede realizar la integración con BioStar a partir de la API pública, y conocer si la información que se maneja es suficiente para que se pueda llevar a cabo la integración, y de igual forma saber qué información adicional se necesita para este propósito. A partir del informe generado, se obtuvo información muy relevante para poder relacionar de qué forma se puede llevar a cabo la integración con la API de BioStar, tanto de forma simulada como de forma real, y poder validar que la información que se maneja, sobre todo para el tema de relacionar los dispositivos de hardware de BioStar con las sedes en las que se encuentran, para así poder tener control sobre los eventos de entrada y salida. Esto permitió poder añadir al modelado de datos información necesaria para este proceso, y de igual forma poder tener una base para realizar la implementación.
